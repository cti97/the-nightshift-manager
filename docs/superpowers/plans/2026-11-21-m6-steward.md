# M6 — the steward

Spec §7 (roles), §8 (dynamic capabilities), §10 (sandbox), §15 (API), §18 (build order).

M6 is the always-on box: a Raspberry Pi that runs the reflex path, keeps the private lane alive at
3am, advertises what it can reach, probes the cloud endpoint, and serves a read-only copy of the
board when the VPS is down. Plus the two things that make a fleet installable rather than
hand-assembled: `nsm agent install` and a signed `/dist` channel.

## Task 1 — the reflex executor (done)

`internal/agent/reflex.go`, `--executor agentic|reflex`. One provider call, no tool definitions, no
sandbox; an empty answer fails the run; the settle is checked against the budget like the loop's.
Provider construction was extracted to `providerDeps` so both executors share one implementation of
the auth_ref rules.

Acceptance: `TestReflexIsOneCallWithNoTools`, `TestReflexRefusesAnEmptyAnswer`,
`TestReflexFailsOverBudget`, `TestAgentRunChoosesTheExecutor`.

## Task 2 — `nsm agent install` (done)

Launchd agent (macOS) and systemd **user** unit (Linux), a wrapper that sources a `0600` env file,
and `--print`. The token never appears in a unit file or plist: those are world-readable and travel
into every backup of the machine.

Acceptance: `TestTheUnitFilesCarryNoSecret`, `TestInstallRefusesAnUnquotableToken`,
`TestTheLaunchdPlistIsWellFormed`, `TestTheSystemdUnitRestartsAndIsPerUser`,
`TestInstallPrintWritesNothing`.

## Task 3 — dynamic `lan:*` capabilities (done)

`internal/agent/lan.go`, `--lan service=host:port,…`. Each heartbeat dials each service and declares
`lan:<service>` only while it answers. The dial is the promise: nothing speaks SMB or CUPS, and a
deeper check would be a lie a placement decision could act on.

Acceptance: `TestLanProbeSpecIsStrict`, `TestReachabilityIsADial`,
`TestTheHeartbeatDeclaresOnlyReachableServices`.

## Task 4 — the endpoint canary

**Files:** `internal/board/canary.go`, `internal/board/http.go`, `internal/agent/canary.go`,
`cmd/nsm/main.go`.

The Pi probes the cloud endpoint on a schedule *from its own network path* — the whole point is that
it reaches the endpoint the way a node would, which the VPS cannot test for it. The board gains
`GET /canary` (node auth: the endpoints a steward may canary, with base_url and provider) and
`POST /canary/{id}` (node auth: `{ok, latency_ms, reason}`), which flips `endpoints.health` and
writes exactly one event per *change*, not per probe. The agent gains `--canary 60s`.

Acceptance: `TestACanaryFlipsHealthAndWritesOneEventPerChange` (a down→up→up sequence writes one
event), `TestACanaryFromAnotherNodeIsRefused`, `TestACanaryReportsLatency`,
`TestTheCanaryLoopStopsWithItsContext`.

## Task 5 — the read-only replica

See `docs/superpowers/designs/2026-11-21-read-only-replica.md` for the memo and its caveat: the first
task is an audit that every board-view column is evented, because the memo's "project events, no
snapshot" decision is only sound if it is. Not scheduled until that audit exists.

## Task 6 — `/dist` and signing

**Files:** `internal/board/dist.go`, `scripts/sign-release.sh`, `cmd/nsm/main.go`.

The manager serves `GET /dist/manifest` and `GET /dist/{os}/{arch}/nsm`, bearer-authenticated (never
public: the artifacts reveal the fleet). `nsm agent install --version X` fetches, verifies the
signature against a key pinned at install time, and replaces the binary atomically.

This one needs a decision that is not mine to take alone: **which signing tool and where the private
key lives.** minisign is the spec's choice (§18) and is one small dependency; the key must live off
the manager (a signature the manager can forge protects nobody from a compromised manager).

Acceptance (once decided): `TestTheManifestNamesEveryTarget`, `TestDistRequiresTheAdminToken`,
`TestAnUnpinnedKeyIsRefusedAtInstall`.

## What M6 does not do

- No dynamic model discovery on the Pi; the endpoint list is the manager's.
- No write-through replica (see the memo: a Pi that can write is split-brain on the LAN).
- No Windows service until `nsm agent install` has a Windows unit to generate.
